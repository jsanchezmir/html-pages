6. Metrics lifecycle

Start

Experiment fetchers create a UUID resourceKey and emit an image request started event with requested width and height.

Timed provider work

The duration clock covers the selected provider operation. It includes cache lookup, download, decoding, and provider processing.

Finish

The clock stops before deferred metadata is evaluated, keeping expensive Kingfisher data serialization outside image_duration_ms.

Cache source

Each provider maps its native result to Memory, Disk, Network, or Unknown.

Duplicate work

An actor keyed by image ID, size, crop mode, and grayscale marks whether an identical request was already in flight.

Reporters

The composition root fans metrics to local logging and Datadog RUM. The ordinary non-experiment path uses a no-op reporter.

Datadog attributes

image_service, requested dimensions, image_outcome, image_cache_source, image_duration_ms, duplicate state, response format, decoded dimensions, decoded memory cost, and encoded size when available. Raw URLs, image IDs, user IDs, and arbitrary error text are not emitted.

7. Failure, cancellation, and fallback behavior

Missing image ID

The fetch finishes as a failure metric and returns the request item's fallback image.

Provider error

The fetch records failure, returns the fallback, and does not publish a successful image.

Cancellation

A new request or view disappearance cancels the previous task. Cancellation is recorded as cancelled when the provider operation throws while cancelled.

Placeholder

The cache check is used to decide whether the placeholder should be shown while the selected provider loads the image.

Default path

Without an explicit service, the normal modifier uses the existing CustomerFoundation/SDWebImage application service, preserves the existing rendering behavior, and installs NoOpRemoteImageMetrics, so it emits no experiment metrics.

Invalid toggle

Empty, missing, malformed, sdwebimage, or unknown values resolve to the SDWebImage control.
